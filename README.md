# Indian E-Commerce Sales Analytics

## About the Project
This project focuses on analyzing Indian e-commerce sales data using Python. It explores sales performance, customer behavior, and product trends to identify useful business insights.

## Dataset
The dataset contains three CSV files:

- `sales.csv` — Order details, sales amounts, discounts, payment methods, and order status.
- `customers.csv` — Customer demographics, locations, and customer tiers.
- `products.csv` — Product categories, brands, prices, ratings, and stock information.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Data Understanding
2. Data Cleaning and Validation
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights

## Key Areas of Analysis
- Sales trends over time
- Product and category performance
- Customer behavior and spending
- State-wise sales performance
- Payment method analysis
- Order status and return analysis
- Discount and sales analysis

## Objective
The goal is to understand the dataset, identify patterns, and generate insights that can help businesses make better decisions.
